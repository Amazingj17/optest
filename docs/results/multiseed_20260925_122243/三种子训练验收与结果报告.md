# 三种子训练验收与结果报告

实验批次：`multiseed_20260925_122243`；核验日期：2026-09-28。

三个种子的九次模型训练及全部验证评估已完成，训练预算、数据划分、检查点来源和逐场景结果通过验收。
组合策略平均归一化 makespan 较 HEFT 降低约 8.18%，但主要收益来自搜索；目前不能声称 HRL 训练带来稳定、显著的额外收益。

## 2. HRL 的训练收益与组合归因

| seed | HRL 最佳 step | 初始 ratio | 第 1 轮 | 第 2 轮 | 第 3 轮 | 组合相对搜索严格改善场景 | HRL 带来的平均 ratio 降低 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 2026 | 864 | 0.999908 | 0.997358 | 1.002619 | 1.006308 | 2 / 108 | 0.000048078 |
| 2027 | 0 | 0.999908 | 1.011029 | 1.007827 | 1.029647 | 0 / 108 | 0.000000000 |
| 2028 | 0 | 0.999908 | 1.000515 | 1.015656 | 1.042573 | 0 / 108 | 0.000000000 |

- seed2026 选择第 1 轮 high-only + 固定 EFT 的模型；后续 joint 阶段验证成绩退化。
- seed2027、2028 均选择 step 0 初始模型。这两个模型完成了训练，但训练后的已评估检查点均未优于初始策略；不能称为训练成功提升调度。
- 三个种子最终一轮都劣于初始策略。现有证据不支持继续增加相同配置的训练轮数。
- 三种子 HRL 增量平均为 0.000016026 ratio，即约 0.001603 个百分点；改善仅来自 seed2026 的两个场景。
- seed2026 的组合减纯搜索配对差值 95% bootstrap CI 为 [-0.000142353, 0]，另两个种子为 [0, 0]，不支持显著的 HRL 额外收益结论。
- 324 个 seed×场景记录复用了相同 108 场景，不能当成 324 个独立数据样本。

## 3. 验收范围与证据

- 2026/2027/2028；每种子 Residual HRL、Graph PPO、Tier MAPPO 各 2592 episodes、384900 个任务决策、3 轮完整覆盖。
- 总计 23328 episodes、3464100 个任务决策；每模型 864 训练场景，每种子 108 验证场景 / 54 基础 DAG。
- 每种子六方法 648 条记录，独立组合评估 432 条候选/组合记录；候选分数与六方法评估一致，组合逐场景等于候选最小值。
- 对照训练日志、状态、保存的划分、逐场景 HEFT 分母、配置种子和组合所用 checkpoint SHA256；未重新执行调度器。
- source_sha256.json 共记录 121 个文件。当前本地缺少两个历史 smoke 配置；其余文件除 manifest 换行差异外字节 hash 一致，无其他差异。manifest JSON 内容一致，LF 版本与服务器冻结 hash 一致。
- 缺失本地文件：`configs/main_gpu_smoke_seed2026.yaml`, `configs/main_gpu_smoke_seed2026b.yaml`。这不等于服务器训练缺文件，但完整归档应补回这两个配置。
- 当前仅核验已回传产物；未逐文件重新校验原始数据，未重新训练。

## 4. 报告与赛题边界

- validation 同时用于选模与报告；当前没有独立 test 泛化证据。
- experiment.seed 同时影响训练与搜索候选，组合跨种子标准差包含两者的随机性，不能全部解释为 HRL 训练波动。
- 服务器记录为 Ubuntu 20.04.6 LTS，不能据此证明赛题要求的国产开源操作系统适配；需另附真实目标系统开发、运行和测试证据。
- 正式表述建议：“采用 HRL、独立 beam+blocks 搜索及 HEFT 保底的候选选择机制，在固定验证集的三种子实验中，平均归一化 makespan 降低 8.18%。消融表明主要收益来自搜索，HRL 的额外收益有限。”

## 5. 下一步建议

1. 先冻结本批次作为正式三种子验证基线，保留所有种子、初始模型选择情况和消融结果；更新报告时明确算法各部分贡献。
2. 如果继续优化 HRL，先做小规模受控诊断：从 seed2026 第 864 步模型出发，比较固定 EFT、冻结高层仅训练低层和 joint；根据验证改善决定是否扩大训练。
3. 优先核查低层采样与贪心执行差距、更新幅度和奖励归因。现有结果只能定位训练退化现象，尚不能据此认定根因。
4. 定稿前补目标国产系统证据。若协议要求独立 test，冻结方案后再统一评估，不能一边看 test 一边调参。
