# 服务器全模型训练与性能对比操作指南

更新：2026-09-23。对应入口：`scripts/run_server_comparison.py`。

## 1. 本次已经实现什么

- 训练三种神经模型：Residual HRL、Graph PPO、Tier MAPPO。
- 比较六种策略：以上三种、HRL-safe、HEFT、beam + blocks。后三种无需另训，HRL-safe 复用本轮主模型权重；搜索策略不包含神经候选。
- 固定原 864 训练场景、108 验证场景／54 个验证 DAG；不运行 proxy 或 test。
- 从头训练默认 3 个覆盖轮次，各 2592 episodes；主模型第 1 轮高层训练、第 2–3 轮联合训练，每轮完整无放回覆盖。
- 指定 GPU 队列：一张卡顺序运行，多张卡一卡一任务。只使用你显式授权的卡，不自动占用看似空闲的其他 GPU。
- 实时控制台与文件日志、逐回合指标、验证进度、原子状态文件、失败退出。
- 自动进行统一 CPU 单线程评估、六策略比较图、训练曲线和实际预算表。
- 可选择复用已经完成的主模型，明确报告其不同预算和采样方式。

本地已用小型合成场景验证代码链路；这不代表已经替你在远程服务器启动正式训练。单个入口对应一个训练 seed，不自动生成跨 seed 统计。

## 3. 两条运行路线，只选一条

### A. 三种神经模型全部重新训练

适合：希望建立一组匹配场景覆盖的新实验。

先预览：

```bash
python scripts/run_server_comparison.py \
  --output outputs/all_models_seed2026 \
  --gpus 0 1 2 --epochs 3 --seed 2026 --threads 4 \
  --dry-run
```

`--dry-run` 不创建输出文件、不加载整个数据集、不启动训练；它检查配置和基本协议，复用模式还会读取可信 checkpoint 及完成性记录。它不是 GPU 实际可用性验收。

确认三张卡已经获准使用且没有冲突后，再正式启动：

```bash
mkdir -p logs
nohup python -u scripts/run_server_comparison.py \
  --output outputs/all_models_seed2026 \
  --gpus 0 1 2 --epochs 3 --seed 2026 --threads 4 \
  > logs/all_models_seed2026.log 2>&1 &
echo $! > logs/all_models_seed2026.pid
```

通常第一批任务分配为 GPU 0→主模型、GPU 1→Graph PPO、GPU 2→Tier MAPPO；具体以 `job_started` 事件为准。

**你此前快照里 GPU 0、2 已有其他任务。未确认释放／授权前，不执行三卡命令。** 只有 GPU 1 可用时，将 `--gpus 0 1 2` 改为 `--gpus 1`，三模型会依次运行。两张卡可用时传两个编号即可。

### B. 复用已完成主模型，只新训练两个基线

适合：最短时间得到新主模型参与的六策略比较，避免重复约 12.9 小时的主模型训练。复用的是 `best.pt`，不是第 3000 步的 `latest.pt`。

服务器上的模型原位置预计为 `outputs/main_gpu_3000_seed2026/best.pt`，请先确认：

```bash
ls outputs/main_gpu_3000_seed2026/{best.pt,config.yaml,train_log.csv,summary.json,dataset_audit.json}
python scripts/run_server_comparison.py \
  --output outputs/all_models_reuse_main_seed2026 \
  --gpus 1 --epochs 3 --seed 2026 --threads 4 \
  --reuse-main outputs/main_gpu_3000_seed2026/best.pt \
  --dry-run
```

正式启动（先使用获准空闲的 GPU 1；有两张可用卡可传两个编号）：

```bash
mkdir -p logs
nohup python -u scripts/run_server_comparison.py \
  --output outputs/all_models_reuse_main_seed2026 \
  --gpus 1 --epochs 3 --seed 2026 --threads 4 \
  --reuse-main outputs/main_gpu_3000_seed2026/best.pt \
  > logs/all_models_reuse_main_seed2026.log 2>&1 &
echo $! > logs/all_models_reuse_main_seed2026.pid
```

本地回传副本位于 `outputs/gpu/outputs/main_gpu_3000_seed2026/best.pt`；服务器和本地路径不同，应填写实际路径。checkpoint 同目录的训练日志和 summary 必须保留，旧主模型的 dataset_audit 用于计算实际决策数。

复用检查包括配置 hash、完整连续训练步数、阶段预算、108 场景／54 DAG 的有效结果和种子。不会写入源模型目录。该实验主模型 3000 episodes／411150 决策／840 个已访问场景，基线各 2592 episodes；不是覆盖匹配或等计算预算消融。

## 4. 自动执行顺序

1. 检查固定 manifest 存在、配置协议一致、GPU 可见性；加载数据核验 864/108/108 划分，不执行 test 评估。
2. 写入 run_plan、环境和生成后的配置；每个模型使用独立目录。
3. GPU 队列运行需要新训练的模型，输出日志和 checkpoint。
4. 验证训练完成性；未完成或子进程失败则停止，不产出假的成功比较。
5. 六策略统一 CPU、Torch 单线程、原全量 108 验证；重新计算分数、延迟、配对统计。
6. 自动生成总体、分组、配对差值、端边云分配图及训练历史图。
7. 全部通过后，根目录 `status.json` 标记 `complete`。

默认初始、每轮结束、选中模型最终报告均运行全量验证。`--epochs 1` 是 864 个训练场景的一轮完整训练，不是快速 smoke；此时主模型直接联合训练。没有偷偷抽取验证子集的短跑参数。

如在 Slurm 中使用，按调度器分配申请资源。入口检查所请求编号属于已设置的 `CUDA_VISIBLE_DEVICES`；不能为了通过检查随意清除调度器限制。该入口目前接受数字 GPU 编号，不处理 UUID／MIG 标识。CPU 调试可用 `--device cpu`，此时顺序训练，不触碰 GPU。

典型信息（示意，非本次实际训练结果）：

```text

residual_hrl episode_complete ... reward=... high_loss=... low_loss=... coverage=...
```

逐 episode 记录场景、任务数、覆盖量、累计任务决策、奖励、loss、KL、学习率、耗时；HRL 分开记录高低层。验证开始、每 10 场景及结束打印进度。单个复杂场景可能长时间处理，进度不会每秒跳动；不是每个神经动作都打印日志。

每个模型的 `events.jsonl` 和 CSV 持续 flush。根状态表示流水线事件，各模型状态表示其训练进度。状态原子替换，避免监控读到半截 JSON。

## 7. 失败、中断和续跑边界

- 新运行目录必须为空，不允许覆盖历史结果。不同配置、seed 或重跑用不同目录名。
- 某个子进程失败，流水线记录失败并停止它启动的其他尚在运行的子进程；不会结束外部原有任务。Ctrl+C／SIGTERM 也会进行子进程清理；强制 kill -9 不能保证清理。
- 主模型每个 episode 原子保存 latest，图基线在初始验证和每轮结束保存 checkpoint；图基线的轮内故障可能丢失该轮计算，但增量 CSV 保留。
- **此入口没有实现精确断点续训。** 不提供不存在的 --resume 参数。失败后保留目录和日志，用新目录重新运行；不要把不完整 checkpoint 当作已完成模型。
- 主模型已经完成时，可以通过 --reuse-main 避免重新训练主模型。复用要求完成性记录可核验。
- 如果模型均已完成，仅评估／绘图失败，不必重训；使用下面独立命令完成剩余阶段。

独立重做比较，输出一个新的比较目录：

```bash
python scripts/compare_main_models.py \
  --main-checkpoint outputs/all_models_seed2026/training/residual_hrl/best.pt \
  --graph-checkpoints \
    outputs/all_models_seed2026/training/graph_ppo/best.pt \

  --search-config outputs/all_models_seed2026/configs/search.yaml \
  --output outputs/all_models_seed2026/comparison_retry
python scripts/plot_main_model_comparison.py \
  --comparison outputs/all_models_seed2026/comparison_retry
python scripts/plot_server_training.py \
  --main-run outputs/all_models_seed2026/training/residual_hrl \
  --graph-runs outputs/all_models_seed2026/training/graph_ppo outputs/all_models_seed2026/training/tier_mappo \
  --output outputs/all_models_seed2026/figures_retry
```

复用路线请相应替换主模型路径。若比较已完成只有绘图失败，仅运行相应绘图命令。旧 manifest 的 CRLF/LF 差异已兼容；真实 JSON 内容变化仍拒绝。不要为绕过协议检查修改 checkpoint hash。
