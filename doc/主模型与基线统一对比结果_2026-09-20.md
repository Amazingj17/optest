# 主模型与图学习基线统一对比结果

> 评估完成：2026-09-18 09:52:53，北京时间。  
> 图表检查与报告整理：2026-09-20。  
> 本轮是已有模型的统一评估，不是重新训练；固定全部 108 个 validation 场景，没有运行 test。

## 一、结论

**主模型已纳入比较，并分别报告纯 Residual HRL、安全组合 HRL-safe 和当前最佳 beam + blocks 搜索版。**

- 在三种纯学习策略中，Residual HRL 的 mean ratio 最低：**0.995168**；Graph PPO 为 **1.016401**，Tier MAPPO 为 **1.098707**。
- 纯 Residual HRL 相对 Graph PPO 有 **88 场胜、20 场负**；相对 Tier MAPPO 有 **97 场胜、11 场负**。它并非每个场景都更好。
- HRL-safe 将均值降至 **0.953510**，并在本次全部场景上不差于 HEFT。
- 独立的 beam + blocks 搜索版均值最低，为 **0.918681**，但平均调度时间最高，为 **5.8966 秒/场景**。
- 六种方法均有 **108/108 合法调度**。搜索和安全组合的收益不能全部归因于神经网络。

这是同一验证协议下的既有模型比较，**不是等训练预算或等参数量的消融实验**，也不是独立 test 泛化成绩。

## 二、总体结果

ratio 定义为每个场景的 makespan / 同场景 HEFT makespan，主指标为逐场景 ratio 的算术平均，越低越好。

| 方法 | 实际类别 | Mean ratio ↓ | Max ratio ↓ | 平均秒/场景 ↓ | P95秒/场景 ↓ |
| --- | --- | ---: | ---: | ---: | ---: |
| HEFT | 参考启发式 | 1.000000 | 1.000000 | 0.2565 | 0.7560 |
| Graph PPO | 纯学习基线 | 1.016401 | 1.956574 | 1.3977 | 4.4033 |
| Tier MAPPO | 纯学习基线 | 1.098707 | 1.576718 | 1.5642 | 3.9107 |
| **Residual HRL** | **主模型，纯学习** | **0.995168** | 2.011220 | **0.7134** | **1.6268** |
| **HRL-safe** | **主模型 + 安全组合** | **0.953510** | **1.000000** | 1.4771 | 3.9638 |
| **beam + blocks** | **独立搜索版** | **0.918681** | **1.000000** | 5.8966 | 18.3117 |

均值相对 HEFT 的归一化改善分别约为：Residual HRL **0.48%**、HRL-safe **4.65%**、搜索版 **8.13%**。这些不是所有场景 makespan 总和的相对下降比例。

纯 Residual HRL 的最差 ratio 约为 **2.0112**，说明平均略优于 HEFT 不等于具备逐场景安全性。安全性由 HRL-safe 的候选保留和最终比较提供，而不是由残差网络本身保证。

本次计时使用相同 CPU、单个 torch 线程，包含策略初始化、完整候选规划和调度回放。它不是神经网络单次 forward 延迟，也没有进行多轮交错计时，结果可能受后台负载影响。不要将这里的耗时与前一次两基线报告的耗时混为同一测量批次。

## 三、如何理解三个主方案版本

| 版本 | 使用的模型与搜索 | 是否有 HEFT 安全兜底 |
| --- | --- | --- |
| Residual HRL | 历史 LSTM 高层任务选择 + GAT 低层资源选择，带 HEFT 残差先验 | 无 |
| HRL-safe | 同一 Residual HRL 完整排程候选 + 历史配置的 16 个扰动候选 + HEFT | 有 |
| beam + blocks | 当前搜索配置的候选、三轮 beam、关键块迁移；**不包含学习候选** | 有 |

HRL-safe 此处不是“主模型叠加全部 beam + blocks 搜索”。三个运行形态单独列出，是为了区分学习贡献与搜索成本，避免把 0.918681 当作纯神经网络成绩。

## 四、配对结果

差值定义为“主方案候选 ratio − 参考基线 ratio”。负数有利于主方案；胜负容差为 1e-9。

| 参考基线 | 主方案候选 | 平均差值 | 按基础 DAG 分组的 95% 区间 | 候选胜/负/平 |
| --- | --- | ---: | --- | --- |
| Graph PPO | Residual HRL | -0.021233 | [-0.036268, -0.005175] | 88/20/0 |
| Graph PPO | HRL-safe | -0.062891 | [-0.090253, -0.042511] | 104/4/0 |
| Graph PPO | beam + blocks | -0.097719 | [-0.137546, -0.071951] | 108/0/0 |
| Tier MAPPO | Residual HRL | -0.103539 | [-0.139852, -0.062845] | 97/11/0 |
| Tier MAPPO | HRL-safe | -0.145196 | [-0.169394, -0.121049] | 103/5/0 |
| Tier MAPPO | beam + blocks | -0.180025 | [-0.198354, -0.163311] | 108/0/0 |

区间使用 54 个基础 DAG 成组重采样 1000 次，同一 DAG 的同构/异构实现一起重采样。这里没有进行多重比较校正；validation 参与了算法开发和 checkpoint 选择，因此这些区间只能作为探索性比较，不构成未触碰测试集上的证据。

主模型的纯学习策略在三个规模分组的平均 ratio 均低于两个图基线，但其 50 任务组仍差于 HEFT。安全组合与搜索的主要改善集中于异构资源组。

## 七、公平性与适用范围

| 项目 | 主模型 Residual HRL | Graph PPO | Tier MAPPO |
| --- | ---: | ---: | ---: |
| 历史训练 episode | 150 | 2592 | 2592 |
| 使用的最佳 checkpoint | 第100个 episode | 第2个 epoch | 第2个 epoch |
| 参数量 | 174414 | 31518 | 58979 |
| 本轮追加训练 | 无 | 无 | 无 |

- 模型结构、参数量、训练预算和启发式先验不同，不能把这张表当作严格控制其他变量的网络架构消融。
- 主模型历史训练用过 proxy 辅助选优；本次评估没有 proxy，全部使用固定的 108 个 validation 场景。
- 所有学习模型这里只对应一个 seed，不能推断跨 seed 稳健性。
- HRL-safe 的学习权重与纯 Residual HRL 相同，额外收益伴随搜索；beam + blocks 则不训练神经网络。
- 当前结果支持“这些已训练模型在本次验证集上的表现排序”，不支持声称某算法在任意训练预算或未知数据上必然更优。
