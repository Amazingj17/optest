# 服务器三种子训练与组合评估操作手册

适用于当前代码，操作系统为 Linux，命令在项目根目录执行。
本文提供操作步骤，不会自动在服务器启动任务。

文档校验记录（2026-09-24）：13 个 Bash 代码块和 5 段内嵌 Python 通过语法检查；
三个种子的 CPU dry-run 均通过，未启动训练、未创建训练输出。
验收脚本另用现有 seed2026 产物完成只读字段兼容性检查；这不代表新三种子实验已完成，
服务器的 CUDA、数据及资源可用性仍由正式运行前的预检确认。

## 1. 本次训练范围

默认采用 **2026、2027、2028 三个种子**，每个种子从头训练三个模型：

| 内容 | 每个种子的要求 |
| --- | --- |
| 神经模型 | Residual HRL、Graph PPO、Tier MAPPO |
| 数据 | 原 432 基础 DAG／864 训练场景；54 基础 DAG／108 validation 场景 |
| 规模 | 50、100、300 个任务 |
| 预算 | 每模型 3 轮完整覆盖，2592 episodes、384900 个任务决策 |
| HRL 阶段 | 第 1 轮 high-only＋固定 EFT；第 2、3 轮 joint |
| 原有比较 | HEFT、三种神经策略、HRL-safe、beam+blocks，共 6 策略 |
| 新增比较 | 该种子的 HRL＋独立 beam+blocks＋HEFT 组合 |
| 验证 | 全量 108 场景、CPU 单线程，不用 proxy，不评估 test |

三个种子合计 **9 次模型训练、23328 episodes、3464100 个任务决策**。
每个种子的 HRL-safe 和组合策略复用该种子的 HRL `best.pt`，不需要再训练。

推荐顺序：**一个种子内三模型按 GPU 槽位并行，种子之间顺序运行**。
三张卡时通常是一卡一模型；一张卡时自动按队列顺序训练三个模型。
不要在同三张卡上同时启动三个种子的流水线，否则会同时争抢最多九个模型任务。

### 已经有 seed2026，是否还要重跑？

推荐三种子全部使用当前冻结代码重新训练。旧 seed2026 使用的是此前代码版本；
现在阶段控制、日志、分叉和其他工程实现已有改动，不应未经核验直接混合成同版本三种子实验。
若以后决定复用旧种子，必须明确报告代码版本差异，并完成等价性审计。本手册不采用复用路线。

本次验证“当前方案的跨种子稳定性”，不引入动态高层特征、搜索教师或新的奖励。
三种子不保证提高平均成绩，不应只报告最好的 seed。

## 5. 生成批量执行脚本

此脚本每个种子先完成三模型训练和六策略比较，再执行该种子的独立组合评估。
任何一步失败立即停止；不会自动跳过失败种子或覆盖旧结果。

在项目根目录复制执行以下完整代码块：

```bash
cat > "$RUN_ROOT/run_three_seeds.sh" <<'BASH'
#!/usr/bin/env bash
set -euo pipefail
if (( $# < 3 )); then
  printf 'Usage: bash run_three_seeds.sh PROJECT_DIR RUN_ROOT GPU_ID [GPU_ID ...]\n' >&2
  exit 2
fi
PROJECT_DIR=$1
RUN_ROOT=$2
shift 2
GPUS=("$@")
cd "$PROJECT_DIR"
export PYTHONPATH="$PROJECT_DIR/src"
export MPLBACKEND=Agg
export PYTHONUNBUFFERED=1
export PYTHONIOENCODING=utf-8
export CUBLAS_WORKSPACE_CONFIG=:4096:8
export OMP_NUM_THREADS=4
export MKL_NUM_THREADS=4

for SEED in 2026 2027 2028; do
  # Refuse code/config changes between seeds.
  python - "$RUN_ROOT/source_sha256.json" <<'PY'
from pathlib import Path
import hashlib, json, sys
expected = json.loads(Path(sys.argv[1]).read_text(encoding='utf-8'))
bad = [p for p, digest in expected.items()
       if not Path(p).is_file() or hashlib.sha256(Path(p).read_bytes()).hexdigest() != digest]
if bad:
    raise SystemExit('Source/config changed: ' + ', '.join(bad))
PY

  printf '%s\n' "$SEED" > "$RUN_ROOT/active_seed.txt"
  MODEL_RUN="$RUN_ROOT/all_models_seed${SEED}"
  python -u scripts/run_server_comparison.py \
    --output "$MODEL_RUN" --gpus "${GPUS[@]}" \
    --epochs 3 --seed "$SEED" --threads 4 \
    2>&1 | tee "$RUN_ROOT/logs/all_models_seed${SEED}.log"

  # Generate a hybrid config bound to THIS seed, never to the old seed2026 model.
  python - "$MODEL_RUN" "$RUN_ROOT" "$SEED" <<'PY'
from pathlib import Path
import json, sys, yaml
model_run, root, seed = Path(sys.argv[1]), Path(sys.argv[2]), int(sys.argv[3])
status = json.loads((model_run / 'status.json').read_text(encoding='utf-8'))
assert status['status'] == 'complete' and status['seed'] == seed
config = {
    'checkpoint': str(model_run / 'training/residual_hrl/best.pt'),
    'search_config': str(model_run / 'configs/search.yaml'),
    'split': 'validation',
    'output_dir': str(root / f'hybrid_seed{seed}'),
}
with (root / f'hybrid_seed{seed}.yaml').open('x', encoding='utf-8') as handle:
    yaml.safe_dump(config, handle, sort_keys=False)
PY

  OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
    python -u scripts/evaluate_independent_hybrid.py \
    --config "$RUN_ROOT/hybrid_seed${SEED}.yaml" \
    2>&1 | tee "$RUN_ROOT/logs/hybrid_seed${SEED}.log"

  python - "$RUN_ROOT/hybrid_seed${SEED}/status.json" <<'PY'
from pathlib import Path
import json, sys
s = json.loads(Path(sys.argv[1]).read_text(encoding='utf-8'))
assert s['status'] == 'complete' and s['num_scenarios'] == 108 and s['num_base_dags'] == 54
assert s['test_evaluated'] is False
PY
done
printf 'All three seeds completed. Run the acceptance/aggregation block in the manual.\n' > "$RUN_ROOT/batch.complete"
BASH
```

脚本没有 `--reuse-main`，也没有 `--fork-from`；本批次是三模型 × 三种子从头训练，
不是上一阶段 A/B 冻结分叉实验。

## 8. 完成后的自动验收与三种子汇总

以下脚本在三个种子全部完成后执行。它按 **每个种子的 mean_ratio** 计算跨种子均值与样本标准差，
不把 3×108 场景当成 324 个独立训练重复。
如果你重新登录过服务器，先设置本批次 `RUN_ROOT`。

```bash
python - "$RUN_ROOT" <<'PY'
from pathlib import Path
import hashlib, json, sys
import numpy as np
import pandas as pd
import yaml

root = Path(sys.argv[1])
seeds = [2026, 2027, 2028]
methods = ['heft','graph_ppo','tier_mappo','residual_hrl','hrl_safe','search_blocks']
rows, gains = [], []
reference_manifest = reference_scenes = None
for seed in seeds:
    run = root / f'all_models_seed{seed}'
    status = json.loads((run/'status.json').read_text(encoding='utf-8'))
    assert status['status']=='complete' and status['seed']==seed and not status['test_evaluated']
    plan = json.loads((run/'run_plan.json').read_text(encoding='utf-8'))
    assert plan['new_episodes_per_model']==2592 and plan['coverage_epochs']==3
    assert plan['reused_main'] is None
    frame = pd.read_csv(run/'comparison/per_scene_all.csv')
    assert len(frame)==648 and set(frame.method)==set(methods)
    assert not frame.duplicated(['method','scenario_id']).any()
    assert frame.valid_schedule.all() and np.isfinite(frame.ratio).all()
    assert frame.groupby('method').scenario_id.nunique().eq(108).all()
    assert frame.groupby('method').base_dag_id.nunique().eq(54).all()

    manifest = json.loads((run/'training/residual_hrl/split_manifest.json').read_text(encoding='utf-8'))
    current = frame.loc[frame.method=='heft', ['scenario_id','base_dag_id','heft_makespan']].sort_values('scenario_id').reset_index(drop=True)
    if reference_manifest is None:
        reference_manifest, reference_scenes = manifest, current
    else:
        assert manifest == reference_manifest
        assert current[['scenario_id','base_dag_id']].equals(reference_scenes[['scenario_id','base_dag_id']])
        assert np.allclose(current.heft_makespan, reference_scenes.heft_makespan, rtol=0, atol=1e-9)

    for method in ['residual_hrl','graph_ppo','tier_mappo']:
        folder = run/'training'/method
        model_status = json.loads((folder/'status.json').read_text(encoding='utf-8'))
        assert model_status['status']=='complete'
        cfg = yaml.safe_load((folder/'config.yaml').read_text(encoding='utf-8'))
        assert int(cfg['experiment']['seed']) == seed
        if method != 'residual_hrl':
            assert int(cfg['training']['seed']) == seed
        assert cfg['evaluation']['proxy_scenarios']==0
        log = pd.read_csv(folder/'train_log.csv')
        assert len(log)==2592 and log.scenario_id.nunique()==864
        assert int(log.num_tasks.sum())==384900
        assert log.groupby('epoch').scenario_id.nunique().tolist()==[864,864,864]
        assert (folder/'best.pt').is_file() and (folder/'latest.pt').is_file()
    summaries = pd.read_csv(run/'comparison/comparison.csv')
    for _, row in summaries.iterrows():
        rows.append(dict(seed=seed, method=row['model'], mean_ratio=float(row['mean_ratio']),
                         mean_inference_time_ms=float(row['mean_inference_time_ms']),
                         num_scenarios=int(row['num_scenarios'])))

    hybrid = root/f'hybrid_seed{seed}'
    hs = json.loads((hybrid/'status.json').read_text(encoding='utf-8'))
    assert hs['status']=='complete' and hs['seed']==seed and not hs['test_evaluated']
    hf = pd.read_csv(hybrid/'per_scene_all.csv')
    assert len(hf)==432 and hf.valid_schedule.all()
    assert set(hf.method)=={'heft','residual_hrl','search_blocks','hybrid'}
    assert not hf.duplicated(['method','scenario_id']).any()
    assert hf.groupby('method').scenario_id.nunique().eq(108).all()
    assert hf.groupby('method').base_dag_id.nunique().eq(54).all()
    for method in ['heft','residual_hrl','search_blocks']:
        matched = hf[hf.method==method].merge(frame[frame.method==method], on='scenario_id', validate='one_to_one', suffixes=('_hybrid','_six'))
        assert len(matched)==108
        assert np.allclose(matched.ratio_hybrid, matched.ratio_six, rtol=0, atol=1e-9)
    pv = json.loads((hybrid/'provenance.json').read_text(encoding='utf-8'))
    expected = run/'training/residual_hrl/best.pt'
    assert pv['checkpoint_sha256']==hashlib.sha256(expected.read_bytes()).hexdigest()
    summary = json.loads((hybrid/'hybrid/summary.json').read_text(encoding='utf-8'))
    rows.append(dict(seed=seed,method='hybrid',mean_ratio=summary['mean_ratio'],
                     mean_inference_time_ms=summary['mean_inference_time_ms'],num_scenarios=summary['num_scenarios']))
    contribution = json.loads((hybrid/'attribution.json').read_text(encoding='utf-8'))
    gains.append(dict(seed=seed,hrl_strict_improvements=contribution['hrl_strict_improvements'],
                      hrl_mean_ratio_reduction=contribution['hrl_mean_ratio_reduction']))

details = pd.DataFrame(rows)
assert not details.duplicated(['seed','method']).any()
assert details.groupby('method').seed.nunique().eq(3).all()
aggregate = details.groupby('method').agg(
    n_seeds=('seed','nunique'), mean_ratio=('mean_ratio','mean'),
    seed_sample_std=('mean_ratio',lambda x:x.std(ddof=1)),
    min_seed_ratio=('mean_ratio','min'), max_seed_ratio=('mean_ratio','max'),
    mean_inference_time_ms=('mean_inference_time_ms','mean')).reset_index()
target = root/'multiseed_summary'
target.mkdir(exist_ok=False)
details.to_csv(target/'per_seed.csv',index=False)
aggregate.to_csv(target/'mean_std.csv',index=False)
pd.DataFrame(gains).to_csv(target/'hybrid_attribution_by_seed.csv',index=False)
(target/'README.txt').write_text(
    'Three full training seeds; sample standard deviation uses ddof=1.\n'
    'Mean ratios are computed per seed before aggregation.\n'
    'Search/portfolio random seeds change with experiment seed; hybrid variation is not solely neural training variation.\n'
    'No test evaluation; validation was used for checkpoint selection.\n',encoding='utf-8')
print(aggregate.to_string(index=False))
print('Acceptance passed:', target)
PY
```

若断言失败，不要删除断言、修改 hash 或手工补齐 CSV 来让验收通过；定位相应种子的实际缺口。
输出目录已存在时，选择新的汇总目录名，保留旧统计。

### 如何解释三个种子

- 报告每个 seed 的成绩以及跨 seed 的 `均值 ± 样本标准差`，保留最差种子。
- 每种子基础 DAG bootstrap CI 与跨种子标准差是不同统计量，不能混用。
- 当前入口的 experiment.seed 同时影响训练采样和搜索／portfolio 的随机候选。
  `resources.mode=dataset` 下场景和资源不随 seed 改变，但纯搜索结果可能随 seed 变化。
- 因此纯神经策略的波动可描述为训练种子波动；组合策略的波动包含训练和搜索随机性的共同影响。
- 同一 seed 内纯搜索与组合使用相同搜索配置及 seed，才能解释 HRL 的增量。
- 如果希望“只改变训练 seed，固定搜索 seed”，需要另行实现并验证种子解耦；当前接口不能直接靠改配置 hash 绕过协议检查。
- 三种子不会证明独立 test 泛化；本轮仍只使用 validation 选模和评估。

## 9. 失败处理与单独补做评估

当前流水线 **不支持精确断点续训**。不要添加不存在的 `--resume`，也不要直接在非空目录重跑。

| 情况 | 处理 |
| --- | --- |
| 训练未完成 | 保留失败目录；在新目录重跑该 seed。只有主模型完成时可以研究 `--reuse-main`，但需明确预算和来源，不默认采用 |
| 三模型完成，六策略评估失败 | 使用已完成的三个 best.pt 单独重评，无须重新训练 |
| 六策略已完成，仅图表失败 | 只重做对应绘图命令 |
| 组合评估失败 | 使用相同 seed 的 best.pt 和 search.yaml，在新输出目录重跑组合评估 |
| seed2026 完成，seed2027 失败 | 保留 seed2026；手动完成失败种子和后续种子，不重新执行原批脚本导致冲突 |

以下示例修复 seed2027 的六策略评估，输出到新目录：

```bash
MODEL_RUN="$RUN_ROOT/all_models_seed2027"
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/compare_main_models.py \
  --main-checkpoint "$MODEL_RUN/training/residual_hrl/best.pt" \
  --graph-checkpoints "$MODEL_RUN/training/graph_ppo/best.pt" "$MODEL_RUN/training/tier_mappo/best.pt" \
  --search-config "$MODEL_RUN/configs/search.yaml" --output "$MODEL_RUN/comparison_retry"
python scripts/plot_main_model_comparison.py --comparison "$MODEL_RUN/comparison_retry"
```

补做组合评估：

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/evaluate_independent_hybrid.py \
  --config "$RUN_ROOT/hybrid_seed2027.yaml" --output "$RUN_ROOT/hybrid_seed2027_retry"
```

若失败发生在生成 hybrid 配置之前，先照第 5 节生成对应配置。
使用 retry 目录时，应在汇总脚本中明确替换该种子的结果路径，并检查独立阶段完成状态。
原流水线根 status 可能仍为 failed；不能手工改成 complete。
第 8 节默认验收的是未中断标准路径，retry 情况需要按实际完成证据调整路径和验收入口。
